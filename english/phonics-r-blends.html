👥 R 家族连缀 · br cr dr fr gr pr tr

一个辅音 + r，舌头卷起来发清晰的 /r/

📖 R 家族连缀——r 要发得响！

R 家族连缀，就是一个辅音 + 字母 r。r 在词首发清晰的 /r/（舌头卷起来，不碰牙齿）。

👄 发音诀窍：先发第一个辅音（b / c / d / f / g / p / t），舌头立刻卷起来发 /r/，两个音一口气黏在一起。别读成 /ə/——不是「bə-read」，是 br-ead！

🔹 词首 R 连缀（br cr dr fr gr pr tr）

R 家族只有词首没有词尾——因为 r 跑到词尾会变身成「r 控元音」（ar / er / ir / or / ur，后面 r 控元音会专门学）！

🎯 口诀：辅音加 r 卷舌头，词首 br-cr-dr，词尾 r 就变身！
