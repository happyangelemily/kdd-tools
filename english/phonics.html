1
🔰 入门预备与字母基础
磨耳朵 → 语音意识 → 26个字母名与字母音 → 元音和辅音
耳朵有充足语感积累、能自主拆音；记牢 26 字母音形；分得清元音和辅音
字母名 vs 字母音 26字母全辨析 · 44音素参考 → 分清元音和辅音 主唱🎤伴奏🥁 · 元音桥拼读 →
2
🧱 CVC 与辅音系统拓展
CVC 短元音 → 辅音二合音 (sh/ch/th/wh/ck/ng/ph) → 辅音连缀 (bl/str…) → CCVC / CVCC / CCVCC 综合
任何带辅音组合的短元音单音节词，见词就能拼
CVC 短元音单词 拼读最基础结构 · 听音分拣 → 二合音融入CVC sh/ch/th/wh/ck/ng/ph · 双层三明治 → L 家族连缀 bl cl fl gl pl sl · 词尾 -ld -lf -lk -lp -lt → R 家族连缀 br cr dr fr gr pr tr · 只有词首 → S 家族连缀 sc sk sm sn sp st sw · 三字母 + 词尾 →
3
✨ 元音变脸与长元音体系
魔法 e (CVCe) → 长元音二合音 (ai/ay, ee/ea, oa/ow) → 双元音与特殊元音 (oi/oy, ou/ow, au/aw, oo) → R 控制元音
80% 的日常单音节词都能自主拼读
4
📐 特殊规则与词法拓展
c/g 软硬音 → 静音字母 (kn/wr/mb) → 隐形长音 (old/ild/ind) → -s/-es · -ed 三种发音 → tion/sion/ture
单音节拼读无死角，熟练掌握常见词形变化、固定词尾发音
5
🔧 多音节拼读进阶
6 类音节类型 → 划分口诀（两分手、一归后、组合不拆分） → 双 / 三音节综合拼读
遇到陌生长单词，可自主拆分、精准拼读，不用死记字母
6
🏁 专项巩固与阅读落地
高频词专项（全程并行） → 综合闯关 → 绘本解码 → 自主阅读
可流利朗读对应难度分级绘本，具备完整的英语自主阅读能力
