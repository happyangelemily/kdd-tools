🔊 /uː/ · oo ue ui ew（长音 u 的全部写法）

ue、ui、ew 都能发 /uː/——跟 oo（moon）声音一样，但写法不同！

📖 /uː/ · 长音 u 的另一面

在 /juː/ 那页，我们学了 u 说自己的名字（cube, few）。但 u_e、ue、ew 有时候不带 y 音，直接发 /uː/！跟 oo（moon）的声音一模一样，只是写法不同。

🌙 oo = /uː/（主力写法）

oo 是 /uː/ 最常见的写法！比如 moon（月亮）——m + oo + n。两个 o 手拉手，发圆圆的 /uː/ 长音。

moon
/muːn/ 🌙
🔊
food
/fuːd/ 🍕
🔊
school
/skuːl/ 🏫
🔊

🔵 ue = /uː/（l/r 后面）

blue（蓝色）——bl + ue = /bluː/。true（真的）——tr + ue = /truː/。注意：ue 在 l/r 后面不发 /juː/，直接发 /uː/！

bl+ ue
blue 🔵
/bluː/ 不带 y
🔊
tr+ ue
true ✅
/truː/ 不带 y
🔊

🍊 ui = /uː/（r, ch, j 后面）

ui 在词中发 /uː/。比如 fruit（水果）——fr + ui + t = /fruːt/。juice（果汁）——j + ui + ce = /dʒuːs/。ui 在 r, ch /dʒ/, j 后面是 /uː/。不过 ui 在 s 后面可能发 /juː/（回看前面学的 suit）。

fr+ ui+ t = fruit 🔊

💨 ew = /uː/（l/r 后面）

ew 在 l/r 后面发 /uː/。比如 blew（吹）——bl + ew = /bluː/。grew（生长）——gr + ew = /ɡruː/。

bl+ ew
blew 💨
/bluː/ 不带 y
🔊
gr+ ew
grew 🌱
/ɡruː/ 不带 y
🔊

⚠️ /juː/ 还是 /uː/？

🥚 彩蛋：ui 的叛徒 + /uː/ 的孤岛词

🔒 ui 不总是 /uː/！

ui 在 r, ch, j 后面发 /uː/（fruit, juice），但也有两个不守规矩的词——ui 在这里发 /ɪ/！

built 🔨
/bɪlt/ ← ui = /ɪ/！
🔊
guilt 😔
/ɡɪlt/ ← ui = /ɪ/！
🔊

🏝️ /uː/ 的孤岛词

这些词读 /uː/，但拼写不属于 u_e、ue、ui、ew 任何一组。不按规则出牌——全靠记住！

do ✅
o → /uː/
🔊
to ➡️
o → /uː/
🔊
who ❓
wh → /h/
🔊
two 2️⃣
w 不发音
🔊
shoe 👟
oe → /uː/
🔊
canoe 🛶
oe → /uː/
🔊

🎉 built/guilt 是叛徒，do/to/who/two 是孤岛！
