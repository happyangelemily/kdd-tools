🔊 /juː/ · u 喊自己的名字！u_e · ue · ew · ui

u_e、ue、ew 都能发 /juː/，ui 偶尔也发——这就是字母 U 的读音！

📖 /juː/ —— u 说自己的名字！

👑 复习：u_e 魔法 e

cube 里的 u_e 发 /juː/——u 在说自己的名字！还记得魔法 e 吗？e 不发音，但它让前面的 u 说自己的名字：c + u + be → /kjuːb/。大部分 u_e 都发 /juː/。

c+ u_e = cube 🧊 🔊

🎯 新朋友：ue = /juː/

ue 在词尾也发 /juː/。比如 cue（提示）——c + ue = /kjuː/。ue 是两个字母一起发 /juː/，就像 u_e 里的 u 和 e 搬到词尾了！

c+ ue = cue 🎯 🔊

🆕 新朋友：ew = /juː/

ew 在词尾发 /juː/。比如 few（几个）——f + ew = /fjuː/。new（新的）——n + ew = /njuː/。ew 和 ue 很像，都爱站词尾，都能发 /juː/！

f+ ew
few 🔢
/fjuː/
🔊
n+ ew
new 🆕
/njuː/
🔊

🆕 新朋友：ui = /juː/（极少数）

ui 在词中也偶尔发 /juː/——不过这种词很少，先认识两个就好：nuisance（讨厌鬼）和 pursuit（追求）。

n+ ui
nuisance 😖
/ˈnjuːsns/
🔊
p+ ui
pursuit 🏃
/pəˈsjuːt/
🔊

🔒 注意：ui 大多时候发 /uː/（fruit、juice、suit /suːt/），那是后面 /uː/ 那页的活。这里先记住 ui 偶尔也能发 /juː/ 就好。

⚠️ /juː/ 还是 /uː/？

🥚 彩蛋：U = You！这些词开头就是 /juː/

你知道吗？字母 U 的读音就是 /juː/——跟单词 you（你）一模一样！所以外国人发短信写 "U" 代替 "you"。

很多以 u 开头的词，u 也发 /juː/：

unicorn 🦄
u + ni + corn = /ˈjuːnɪkɔːrn/
🔊
unit 📐
u + nit = /ˈjuːnɪt/
🔊
uniform 👔
u + ni + form = /ˈjuːnɪfɔːrm/
🔊
university 🎓
u + ni + ver + si + ty
🔊
you 👉
you = /juː/ = U！
🔊

🤫 安静的朋友：knew 和 know

knew（知道，过去式）——k 不发音！kn + ew = /njuː/。跟 new 发音一模一样！knife（刀）、knee（膝盖）也是 k 不发音。kn 开头，k 永远闭嘴！

🎉 记住：U = you，knew = new！
