🍞🍞 结尾加厚了！· CVCC / CVCCC 后置加长

结尾多了一两片面包，中间肉肉还是短元音！

📖 结尾也加厚了！

三明治的结构你已经很熟了：开头面包🍞 + 肉肉🥩 + 结尾面包🍞 = CVC，三个声音。比如：

h+ a+ t = hat 🔊

上一次我们给开头加厚了（CCVC），还记得 stop 吗？这一次，我们给结尾加厚！两个辅音并排站在词尾，这就是 CVCC：

h+ a+ n 🔊+ d 🔊 = hand 🔊 CVCC

🎯 关键：结尾多了一个辅音 → 4 个声音、CVCC 结构。中间的短元音不变！hand 里的 a 还是读 /æ/，和 hat 里一样。

🔺🔺 四片结尾面包：CVCCCC（四连缀）

英语里最极端的结尾——四个辅音叠在一起！全是靠 x = /ks/ 这个「打包字母」做到的：

🧠 关键机制：x 一个字母包了 /k/+/s/ 两个声音。再加 th /θ/ 和 s /s/，4 个辅音音位在词尾一字排开！

📝 英语词尾最多 4 个辅音：/ksθs/（sixths）、/ksts/（texts）、/mpts/（prompts）。靠 x 或塞音+擦音+塞音+擦音的交替排列实现。这就是为什么 sixths 有 6 个声音却只有 6 个字母——x 和 th 各是一个字母代表一个音位。

🥚 彩蛋：x 的秘密 & 特殊结尾

有几个词尾很特别——看起来不像连缀，但里面藏着两个声音！

🔍 x = /ks/：一个字母，两个声音！

box 📦
b + o + x
x = /k/+/s/ = 两个音！
→ 虽然只有3个字母，但是 CVCC
结构：CVCC (b-o-ks)
🔊
fix 🔧
f + i + x
x = /k/+/s/ = 两个音！
→ 也是 CVCC
结构：CVCC (f-i-ks)
🔊

📝 x 是一个「打包字母」：它一个字母就包了 /k/+/s/ 两个声音！所以 box/fix/six/fox/mix 虽然只有 3 个字母，但声音数是 4 → CVCC。数声音，不数字母！

🧬 二合音作为「一个C」参与结尾连缀

结尾的「两片面包」里，有一片可能不是单个辅音，而是一个二合音——两个字母合起来发一个音，在连缀中充当一个C的角色。这就是「单辅音 + 二合音」的结尾组合。点击每个单词的🔊听整词发音，点击拆分字母听单个音：

📝 共同规律：每个词的结尾都是 「一个单辅音 + 一个二合音」——3 个字母，但只有 2 个音位→ 全是 CVCC。字母数 ≠ 声音数！

⚠️ 注意：-rch、-rsh、-rth 类词（如 march/harsh/worth）虽然也是「单辅音+二合音」模式，但中间的元音被 r 影响了发音（r控元音），属于后续学习内容，本页不含。

🧠 核心结论：判断一个词是 CVCC 还是 CVCCC，看结尾有几个音位，不数字母！二合音（ph/ch/sh/th/ck/ng/ge）不管由几个字母组成，只算 1个C。
