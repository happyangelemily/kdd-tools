📦 辅音-le 音节 /əl/

六大音节积木第六种：辅音 + le 自成音节

📦 辅音-le：第六种音节积木

还记得六大音节积木吗？最后一种就是辅音-le：词尾的辅音 + le，le 读轻轻的 /əl/，而且它俩手拉手自成音节！

table → ta + ble → ta·ble
b 和 le 手拉手，组成一个新音节！

/ˈteɪbl/ 桌子
🔊

/ˈlɪtl/ 小
🔊

/ˈæpl/ 苹果
🔊

🔊

🔊

🔊

🔊

🔍 双写小规矩：le 前面是短元音，辅音要双写封住它——lit→little、ap→apple、mid→middle。是长元音（开音节）就不双写——ta→table。

🎯 口诀：辅音 + le 自成音节，读轻轻的 /əl/；前有短元音，辅音双写封住它！

🥚 彩蛋一：辅音-le 的三个特例

① -stle：t 藏起来（静音）——castle 的 t 不发音，stle 只读 /səl/：

castle
/ˈkɑːsəl/ 城堡 🏰
🔊
whistle
/ˈwɪsəl/ 口哨 🎺
🔊
thistle
/ˈθɪsəl/ 蓟 🌿
🔊

② isle / aisle：s 藏起来（静音）——le 只读 /l/（不是 /əl/），整词读 /aɪl/，而且它俩是同音词：

isle
/aɪl/ 岛屿 🏝️
🔊
aisle
/aɪl/ 过道 🚶
🔊

③ -ckle / -ngle：le 前面是二合音——le 前面不是单个辅音，而是二合音 ck(/k/)、ng(/ŋ/)：

pickle
/ˈpɪkəl/ 泡菜 🥒
🔊
jungle
/ˈdʒʌŋɡəl/ 丛林 🌴
🔊

🧠 三个特例都认识即可，不考——它们都是「le 前面的辅音」在捣蛋！

🥚 彩蛋二：/əl/ 的其他拼写 -el / -al / -il

词尾还有 -el、-al、-il 也发 /əl/，但这是元音弱读 schwa（e/a/i 偷懒成 /ə/ + l），不是辅音-le 音节：

camel
/ˈkæməl/ 骆驼 🐫
🔊
animal
/ˈænɪməl/ 动物 🐾
🔊
hospital
/ˈhɒspɪtəl/ 医院 🏥
🔊
pencil
/ˈpensəl/ 铅笔 ✏️
🔊

🧠 分清：table 的 -le 是辅音-le 音节（辅音+le 自成音节）；camel/pencil 的 -el/-il 是弱读 schwa（元音偷懒）。pencil 的 i 弱读成 /ə/，schwa 那课见过它！
