## Cambridge US IPA → KK Symbol Correspondence

Cambridge uses a modified IPA for US English. KK (Kenyon & Knott) is a simplified
subset used in Taiwan and Asia for teaching American pronunciation. The actual AUDIO
is the same — only the symbol notation differs.

## Key Notation Differences: Cambridge US vs KK

```
Cambridge US → KK conversion rules:
  /iː/ → /i/      (drop length mark)
  /uː/ → /u/      (drop length mark)
  /ɑː/ → /ɑ/      (drop length mark)
  /ɔː/ → /ɔ/      (drop length mark)
  /ɝː/ → /ɝ/      (drop length mark)
  /eɪ/ → /e/      (diphthong → single symbol)
  /oʊ/ → /o/      (diphthong → single symbol)
  /e/  → /ɛ/      (epsilon for dress vowel)
  All consonants: identical
```
