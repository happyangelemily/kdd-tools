🍞🍞 面包片加厚了！· CCVC / CCCVC 前置加长

开头多了一两片面包，中间肉肉还是短元音！

📖 三明治加厚了！

还记得三明治吗？面包🍞 + 肉肉🥩 + 面包🍞 = CVC，三个声音、三个字母。比如：

c+ a+ t = cat 🔊

现在我们把开头那片面包加厚——不是一片，是两片！两个辅音并排站在词首，每个都发自己的音，然后接短元音和最后的辅音。这就是 CCVC：

s 🔊+ t 🔊+ o+ p = stop 🔊 CCVC

🎯 关键：开头多了一个辅音 → 4 个声音、CCVC 结构。但中间的短元音不变！stop 里的 o 还是读 /ɒ/，和 top 里一样。

🔺 还能再厚！三片面包：CCCVC

🥚 shr- 和 thr-：连缀还是二合音？

shr- 和 thr- 很特别：sh/th 本身是二合音（一个音），但后面又跟了一个 r 连缀辅音。所以：

shrug
sh = 二合音 /ʃ/ (1音)
+ r = 连缀 /r/ (1音)
= 开头共 2 个音
结构：CCVC
🔊
throb
th = 二合音 /θ/ (1音)
+ r = 连缀 /r/ (1音)
= 开头共 2 个音
结构：CCVC
🔊

🧠 所以 shr-/thr- 的字母数 ≠ 声音数：shrug 虽然开头有 3 个字母（shr），但 sh 合体了 → 实际只有 2 个辅音音位，是 CCVC（不是 CCCVC）！

🔍 对比：str- vs shr-

strap 🎒
s + t + r = 三个音 /s/+/t/+/r/
→ CCCVC（三连缀）
🔊
shrug 🤷
sh + r = 两个音 /ʃ/+/r/
→ CCVC（二合音+连缀）
🔊

📝 结论：shr- 和 thr- 虽然字母看起来像三连缀，但因为是「二合音+单辅音」的组合，本质上属于 CCVC 范畴。记住：数声音，不数字母！
